* Explanation: Instead of running technical calculations on 10,000+ symbols sequentially, parallelize calculations using a ThreadPoolExecutor with 8 workers.
* Benchmark Expectation: 3x - 5x speedup during full stats rebuild.
* Code Changes:
  Move the inner loop logic into a helper function:
  `def _proc_one(sym, grp, snapshots, market):`
  And execute using:
  ```python
  from concurrent.futures import ThreadPoolExecutor, as_completed
  results = []
  with ThreadPoolExecutor(max_workers=8) as executor:
      futures = {executor.submit(_proc_one, sym, grp, snapshots, market): sym for sym, grp in groups}
      for idx, f in enumerate(as_completed(futures)):
          if progress_callback and idx % 50 == 0:
              progress_callback(idx, total_groups)
          res = f.result()
          if res:
              results.append(res)
  ```

5. Chunk gather/einsum operations in basket_screener
-----------------------------------------------------
* Target File: C:\Users\Admin\Desktop\stock test\open code v5 claude prompt\dumbmoney\basket_screener.py
* Line Numbers: 376 - 382, 434 - 441
* Explanation: Doing `close_pivot[indices]` directly on 25000 strings and 4500 dates creates a massive 3D array (4.5 GB memory) which causes memory thrashing and slows down operations. Chunking the array gathering into batches of 2000 strings keeps memory footprint low (360 MB) and runs much faster.
* Benchmark Expectation: Up to 15 GB RAM reduction in peak memory, eliminating paging and memory allocation overhead.
* Code Changes:
  Update `_gather_einsum` to process in chunks:
  ```python
  def _gather_einsum(close_pivot, indices, weights):
      n_strings = indices.shape[0]
      n_dates = close_pivot.shape[1]
      result = np.zeros((n_strings, n_dates), dtype=np.float32)
      chunk_size = 2000
      for i in range(0, n_strings, chunk_size):
          idx_chunk = indices[i:i+chunk_size]
          w_chunk = weights[i:i+chunk_size]
          result[i:i+chunk_size] = np.einsum('bi,bid->bd', w_chunk, close_pivot[idx_chunk])
      return np.nan_to_num(result, nan=0.0)
  ```
  Update `_compute_basket_ohlc` in the same way.
